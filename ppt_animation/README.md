# PPT 깔끔한 애니메이션 + 동영상 만들기

`AddAnimationAndExport.bas` 매크로가 하는 일:

| 항목 | 설정 |
|---|---|
| 슬라이드 전환 | 부드럽게 페이드 0.7초 (모든 슬라이드 동일) |
| 개체 등장 | 위→아래, 왼→오른 순서로 **페이드 인** 0.6초, 간격 0.3초 |
| 제외 | 슬라이드 전체를 덮는 배경 그림, 빈 자리표시자 |
| 진행 | 클릭 없이 자동 (애니메이션 끝난 뒤 3초 머묾) |
| 동영상 | 1080p, 30fps MP4 |

효과는 한 가지(페이드)만 써서 지저분하지 않게 했습니다.

## 사용 방법 (Windows PowerPoint)

1. 원본 `박은영동영상만들기261013.pptx` 는 건드리지 않습니다. 매크로가 **`박은영동영상만들기261013_애니메이션.pptx`** 라는 새 이름으로 저장한 뒤 작업합니다.
2. PPT 파일 열기 → `Alt + F11` (VBA 편집기)
3. 메뉴 **파일 → 파일 가져오기** → `AddAnimationAndExport.bas` 선택
   - 한글이 깨지면: .bas 파일을 메모장으로 열어 **ANSI** 인코딩으로 다시 저장한 후 가져오세요.
4. VBA 창 닫기 → `Alt + F8` → **ApplyCleanAnimations** 실행
5. `F5`로 슬라이드 쇼를 보며 확인 (마음에 안 드는 슬라이드는 직접 수정 가능)
6. `Alt + F8` → **ExportVideo** 실행
   → 같은 폴더에 **`박은영동영상만들기261013_동영상.mp4`** 생성

## 조정하기

`.bas` 파일 맨 위 상수만 바꾸면 됩니다.

- `SLIDE_HOLD` : 슬라이드에 머무는 시간 (기본 3초, 글이 많으면 5초 추천)
- `ANIM_DURATION` / `ANIM_GAP` : 등장 속도/간격
- `ANIM_SUFFIX` / `VIDEO_SUFFIX` : 새 파일 이름 뒤에 붙는 말 (원하는 이름으로 변경 가능)
- `VIDEO_HEIGHT` : 720 으로 바꾸면 파일 용량이 작아짐

> 매크로 없이 하고 싶다면: **파일 → 내보내기 → 비디오 만들기 → "기록된 시간 및 내레이션 사용"** 으로도 같은 결과를 얻을 수 있습니다 (4번까지 한 뒤).
